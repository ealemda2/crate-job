# Domain Docs

Before exploring, read **`GLOSSARY.md`** at the repo root and the ADRs in **`docs/adr/`** that touch the area you're working in. If a term you need isn't there, use the closest glossary term rather than inventing one; the `/domain-modeling` skill adds terms when they actually get resolved.
